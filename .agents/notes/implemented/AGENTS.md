# AGENTS.md — 已实现笔记

这些 Agent Note 描述已发布的决策。遵循[根指令](../../../AGENTS.md)与 [Agent Note 格式](../README.md#文件格式)。

## 让已实现笔记与实际发布保持一致

改变路径、符号、默认值或机制的同一变更内，同步更新对应笔记；就地重写过期事实，不追加变更历史。

当一篇已发布笔记不再可能指导未来工作时，通过 [archive-agent-notes](../../skills/archive-agent-notes/SKILL.md) 归档它，而不是继续维护。

### 这不是改写「决策」的许可

就地更新的只是事实性实现（路径、名称、结构、默认值）。决策或 rationale 的反转需要新笔记并交叉链接；完全被 supersede 的旧笔记只能按 [Agent Note 规则](../README.md#何时必须写)的合并规则删除。

# AGENTS.md — Agent Notes

Agent Note 是由 agent 写成的轻量 RFC / 决策记录：保存 rationale、被否决的替代方案、后果与必需的验证——代码与普通文档承载不了的那部分。完整规则见 [README.md](README.md)。

**每新增一篇 Agent Note 都触发 supersession 检查**：在活动树（proposed/implemented/rejected）中检索覆盖同一决策或机制的旧笔记，按 [archive-agent-notes](../skills/archive-agent-notes/SKILL.md) 技能分类处置全量/部分 supersession，同一变更内完成归档或交叉链接；不要把已知的重叠留给日后的语料审计。

[`archived/`](archived/AGENTS.md) 下的文件是冻结的历史快照：永不编辑，也不作为当前行为的权威。
